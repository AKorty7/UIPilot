# UIPilot repository

The Unity project is in `UIPilot/`; `tools/` holds the art, store and docs tooling
that is not shipped. The project brief, `UIPilot/CLAUDE.md`, is imported below, and
it imports the binding rules in `UIPilot/.cursorrules`. Paths in the brief are
relative to `UIPilot/`, so its `../tools/` is `tools/` here.

Start with the brief's **Where we left off** section: it says what is waiting on
the user and what to do next.
